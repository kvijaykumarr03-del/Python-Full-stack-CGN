SQL DATE & TIME FUNCTIONS
CURDATE(): Current date.
CURTIME(): Current time.
NOW(): Current date and time.
DATE(): Extract date part.
TIME(): Extract time part.
YEAR(): Extract year.
MONTH(): Extract month.
DAY()/DAYOFMONTH(): Extract day of the month.
WEEK(): Extract week number.
DAYOFWEEK(): Extract day of the week.
DATE_ADD(): Add time to a date.
DATE_SUB(): Subtract time from a date.
DATEDIFF(): Difference between two dates.
TIMESTAMPDIFF(): Difference between two DATETIME values.
STR_TO_DATE(): Convert string to date.
DATE_FORMAT(): Format a date.
FROM_UNIXTIME(): Convert Unix timestamp to date.
UNIX_TIMESTAMP(): Convert date to Unix timestamp.


1. CURDATE() - Current Date
Description: Returns the current date in YYYY-MM-DD format (no time).
SELECT CURDATE() AS current__date;

Output:
+-------------+
| current_date|
+-------------+
| 2024-11-28  |
+-------------+


2. CURTIME() - Current Time
Description: Returns the current time in HH:MM:SS format (no date).
SELECT CURTIME() AS current_time;

Output:
+--------------+
| current_time |
+--------------+
| 14:32:45     |
+--------------+


3. NOW() - Current Date and Time
Description: Returns the current date and time in YYYY-MM-DD HH:MM:SS format.
SELECT NOW() AS current_datetime;

Output:

+---------------------+
| current_datetime    |
+---------------------+
| 2024-11-28 14:32:45 |
+---------------------+

Q1. Display employee names, age, years of experience, and retirement year (assume retirement at age 60).
SELECT emp_name,
   	TIMESTAMPDIFF(YEAR, birth_date, CURDATE()) AS age,
   	TIMESTAMPDIFF(YEAR, joining_date, CURDATE()) AS experience,
   	YEAR(birth_date) + 60 AS retirement_year

FROM employee_attendance

SET Operators
-----------------
Union : Combines results from two queries and removes duplicate rows. Columns must have the same number and type.

Union All : Combines results from two queries and includes all rows, including duplicates. Columns must have the same number and type

Intersect : Returns rows that are common to both queries. Columns must have the same number and type.
EXCEPT: Returns rows from the first query that are not present in the second query. Columns must have the same number and type.
