JOIN + GROUP BY + ORDER BY + HAVING
Q1. Departments with more than 1 employee, ordered by count.
SELECT d.department_name, COUNT(e.emp_id) AS Employee_Count
FROM Departments d
JOIN Employees e ON d.department_id = e.department_id
GROUP BY d.department_name
HAVING COUNT(e.emp_id) > 1
ORDER BY Employee_Count DESC;

Queries and SubQueries
======================
What is Subquery
====================
a subquery is a query inside another query.
it is written inside parenthesis() and its result is used by the outer query.

it is also called.
inner Query
Nested Query
inner select.

general syntax
-------------
select column-list
from table
where column OPERATOR(SELECT COLUMN FROM TABLE WHERE CONDITION)

purpose of subquery
---------------------
to break down complex problems into smaller queries.
to use the result of one query as input to another
to avoid multiple steps(write in a single Query insted of temp tables)

types of subqueries
-------------------
1. Single-row-subquery
2. multi-row subquery
3. nested subquery.
4. Correlated subquery.
5. Exists/not Exists subquery

1. Single-row-subquery
---------------------------
1. Single Row Subqueries
Single row subqueries return exactly one row and one column. They use comparison operators like =, >, <, >=, <=, !=.
Characteristics:
Returns only one value
Can use single-value comparison operators
If subquery returns no rows or multiple rows, it causes an error
Syntax:
SELECT columns
FROM table
WHERE column operator (SELECT column FROM table WHERE condition);


2. Multi-row Subquery (IN)
—----------------------------------------------------
1. Multi-Row Subqueries with IN
A Multi-Row Subquery returns more than one row. The IN operator is used when you want to compare a value with multiple values returned by the subquery.
Characteristics
Returns multiple rows
Uses the IN operator
Checks whether a value exists in the list returned by the subquery
Equivalent to multiple OR conditions
Most commonly used for matching values
Syntax
SELECT columns
FROM table
WHERE column IN
      (SELECT column
       FROM table
       WHERE condition);


3. Multi-row Subquery (ANY / SOME)
—------------------------------------------------------------------
Multi row subqueries return multiple rows. When using ANY or SOME (they are synonymous), the condition is true if it matches at least one value returned by the subquery.
Characteristics:
Returns multiple values
ANY and SOME are interchangeable
Condition is true if ANY of the values satisfy the condition
Often used with IN, >ANY, <ANY, =ANY, etc.
Syntax:
SELECT columns
FROM table
WHERE column operator ANY/SOME (SELECT column FROM table WHERE condition);


4. Multi-row Subquery (ALL)
—-------------------------------------------------------
The ALL operator means the condition must be true for ALL values returned by the subquery.
Characteristics:
Condition must be true for ALL values in the subquery result
Often used with >ALL, <ALL, >=ALL, <=ALL
>ALL means greater than the maximum value
<ALL means less than the minimum value
Syntax:
SELECT columns
FROM table
WHERE column operator ALL (SELECT column FROM table WHERE condition);


5. Nested Subquery
—-------------------------------------------
Nested subqueries are subqueries within subqueries. They can be multiple levels deep and are executed from the innermost to the outermost.
Characteristics:
Multiple levels of nesting
Inner queries execute first
Can combine different types of subqueries
Useful for complex conditions

Syntax:
SELECT column_list
FROM table
WHERE column = (SELECT column
                FROM table
                WHERE column = (SELECT column
                                FROM table
                                WHERE condition));

6. Correlated Subquery
—---------------------------------------------------------
Correlated subqueries are subqueries that reference columns from the outer query. Unlike regular subqueries that execute once, correlated subqueries execute once for each row processed by the outer query.
Characteristics:
References columns from the outer query
Executes multiple times (once per outer row)
Cannot be executed independently
Often used with EXISTS, NOT EXISTS
Generally slower than non-correlated subqueries
Syntax
SELECT columns
FROM table1 outer_alias
WHERE condition (SELECT column
  	          FROM table2 inner_alias
            	WHERE inner_alias.column = outer_alias.column);


7. EXISTS / NOT EXISTS Subquery
—-------------------------------------------------------------
EXISTS and NOT EXISTS
EXISTS is used to test whether a subquery returns any rows. It returns TRUE if the subquery returns at least one row, FALSE otherwise. NOT EXISTS returns TRUE if the subquery returns no rows.
Characteristics:
Returns TRUE/FALSE (boolean result)
More efficient than IN for large datasets
Often used with correlated subqueries
Stops execution as soon as first match is found
SELECT clause in EXISTS doesn't matter (often use SELECT 1)
Syntax:
SELECT columns
FROM table1
WHERE EXISTS (SELECT 1 FROM table2 WHERE condition);

SELECT columns
FROM table1
WHERE NOT EXISTS (SELECT 1 FROM table2 WHERE condition);
